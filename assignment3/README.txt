Welcome to my polygon search maze! Many thanks to Michael Davis for providing the framework
I used to implement these algos. 

Here I have implemented A* search and Uniform cost search. 

To see the output of my program, please open the index.html file. After regenerating an 
environment, refresh the page to see the new environment and corresponding search paths. 

This program already has an environment generated, but to generate a new one:

$ make
$ ./make_env

To use this program, simply run the Main.java file.

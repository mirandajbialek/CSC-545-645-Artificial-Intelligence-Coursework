## Course Overview

This portfolio contains 10 comprehensive assignments from an advanced AI course covering fundamental and modern artificial intelligence techniques. Each assignment demonstrates hands-on implementation of core AI algorithms and agent-based systems.

## 📚 Topics Covered

- **Agent Design & Environments**: Simple reflex agents, agent-environment interactions
- **Search Algorithms**: Depth-Limited Search, A* Search, Uniform Cost Search
- **Optimization**: Genetic Algorithms, evolutionary computation
- **Constraint Satisfaction**: Backtracking, Forward Checking, AC-3 inference, Min-Conflicts
- **Game Theory**: Minimax algorithm, adversarial search
- **Machine Learning**: Reinforcement learning, neural networks
- **Knowledge Representation & Reasoning**

## 🛠️ Languages & Tools

- **Java** - Core algorithm implementations
- **Python** - Machine learning and reinforcement learning
- **Jupyter Notebooks** - Interactive experiments and visualization
- **Data Structures**: Custom implementations of search trees, constraint graphs, populations
